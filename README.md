# 🚀 Smart Resume Analyzer

A modern web application that allows users to **upload their resume** and **compare it against a job description**. The app extracts skills, calculates a match score, and highlights **matched and missing skills**, helping candidates optimize their resumes for specific roles.

---

## 🌟 Features

- **PDF Resume Upload:** Drag & drop or click to upload resumes (PDF only, max 5 MB).  
- **Job Description Input:** Paste job posting text for analysis.  
- **Skill Extraction & Matching:** Uses a curated skill dictionary (~140 tech and soft skills).  
- **Match Score Visualization:** Animated ring showing match percentage.  
- **Matched & Missing Skills:** Highlights what you already have and what you lack.  
- **Fully Client-Side:** All processing happens in your browser; **no data leaves your device**.  
- **Responsive Design:** Works beautifully on desktop and mobile.  

---

## 📁 Tech Stack

- **Frontend:** HTML, CSS, JavaScript (Vanilla JS)  
- **Design:** Modern, minimal UI with aesthetic animations  
- **Hosting:** Can be hosted on GitHub Pages, Vercel, or Netlify  

---

## ⚡ How It Works

1. Upload your **resume PDF**.  
2. Paste the **job description** into the text area.  
3. Click **Analyze Resume**.  
4. The app extracts skills from both your resume and the job description, matches them, and calculates a **percentage score**.  
5. Visual feedback:
   - Ring chart shows **match percentage**  
   - Matched skills list  
   - Missing skills list
